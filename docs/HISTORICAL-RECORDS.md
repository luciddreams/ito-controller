# Historical engineering records

English is the working language for current revision-L documentation. The following original records are kept unchanged, including their original Dutch text, to preserve the reasoning and evidence behind earlier revisions. They are historical source material, not current fabrication or operating instructions.

| Archive | Purpose |
|---|---|
| `history-rev-j/` | Revision-J engineering reviews, original input-stage studies, Kelvin/BIAS checks, thermal budgets, qualification protocols and review scripts |
| `history-rev-k/` | Revision-K records retained by the project |
| `docs/README-rev-l-original.md` | Snapshot of the original Dutch revision-L package README |

Revision J contains a superseded LTC4365/MOSFET input stage and earlier budgets. The current design uses TPS26630 and the revision-L operating limits. Start with the English README and project description in this repository, not these archives.

Existing JSON reports and component Value fields are machine/reference data. Their original identifiers and historical observations may retain Dutch wording. Third-party PDFs retain their authors' content and language.
