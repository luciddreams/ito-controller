# GitHub-import van revisie L

Doelrepository: https://github.com/luciddreams/ito-controller

Op 26 september 2026 is toegang bevestigd voor de gekoppelde gebruiker `jasjazuidmeer`, inclusief schrijfrechten. De repository was leeg bij de importcontrole.

Dit pakket bevat de huidige revisie L, firmware, productie-output, modellen, uitgebreide documentatie en 40 beschikbare fabrikant-PDF’s. De datasheetindex koppelt alle 202 PCB-posities en vermeldt drie onderdeeltypes waarvoor nog een PDF ontbreekt. De exacte externe NTC’s, fan en thermostaten zijn nog niet gekozen.

De oorspronkelijke PCB, schema- en firmwarebestanden zijn bij deze documentatie-import niet gewijzigd. Bestaande ontwerp- en testresultaten zijn overgenomen; er zijn geen nieuwe fysieke tests uitgevoerd. Historische revisies blijven als zodanig gemarkeerd. Een projectlicentie is nog niet gekozen.
