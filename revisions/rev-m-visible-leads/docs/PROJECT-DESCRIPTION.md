# Revision M project description

The controller retains the original XIAO nRF52840, heater, four TEC channels, temperature inputs, two remote ambient-sensor ports, relay and hardware interlocks.

The revision-specific electrical, mechanical and assembly changes are documented in [README](../README.md) and [design review](../review/DESIGN-REVIEW.md). The root repository describes revision L; its package, stencil, calibration and fabrication details must not be applied to revision M.
